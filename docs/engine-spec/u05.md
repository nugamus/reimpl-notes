# U05: the Saint-Lazare waiting room, the dog and Mazout

Everything U05's unit code (`U05.cpp`, vtable `0x004396d4`, E-0075, E-0360) does on top
of the generic scene: the start hook's fix-ups, the entry, the frame hook (the dog's
routine, Mazout's ambush and its 15-s gauge, the station master's lines, the exit), the
eleven click handlers, and the exit to U06. Conventions are those of `u01.md` and
`u02.md`: `RunFor`, `MoveTo`, `LookAt`, `Say(character, line)`, "effect X at P" (effects
emitter), "voice X at P" (voice emitter), **suspend** / **resume**, `Mnn` = the INFOACT
record with id nn (`infoact.py --file Data/U05/Infoact.bin`), "run Mnn" = its steps, then
its run count (`FUN_0041e4b0`, which does not test the condition), **exhaust Mnn** = mark
it exhausted without running a step (`FUN_0041e3a0`: count := max runs, exhausted := 1).
"Mnn done" = Mnn exhausted.

`s` = 46 (`SCENE.BIN` scale; ambient 255/255/255, FOV 90; E-0366). U05 has no load hook
and no input hook: vtable `+0x10` is the generic load and `+0x40` the generic
`Scene_HandleInput`, so walking and the keys are `movement.md`'s. It has no save chunk
(vtable `+8`/`+0xc` are the generic ones, E-0182): its timers are not saved.

**Walk path** `WalkPath(ms, target, yaw₁, pitch₁)` (`FUN_00419620`, E-0161): as in
`u02.md`, N = ⌊ms · fps / 1000⌋ steps, the eye moves by (target − start)/N, and here yaw
and pitch also move linearly from the camera's to yaw₁ / pitch₁. U05 passes no step
callback, so there is **no ground snap**: the eye follows the straight line, z included.
"Facing X from T" = yaw₁ from `X3d_Convert_To_Polar` of normalise(X − T), where X is the
object's local position (top-level objects: its world origin) and T the target.

## Start (`U05_StartUnit`, E-0361)

Vtable `+0x14`, on a new entry (`a` = 1) and on a restore (`a` = 0):

1. The object `fil` is renamed `*Fil`; it, its children and its **siblings** leave
   collision (`Object_SetNoCollisionTree`, `+0x118` := 1 down `+0x24` and along `+0x28`).
   The animation node `fil` is renamed `*Fil`. A node `Object02` would be renamed
   `*U05_10`; no loaded animation has that name, so it does nothing.
2. The objects `battant02`, `battant` (door leaves) and `col103` leave collision (only
   themselves). Lookups are exact, then first object whose name contains it.
3. The generic start: INFOOBJ, INFOACT, and on a restore the saved chunks
   (`interaction.md`, `save.md`).
4. Collision sphere radius := 32, Z offset := 0 (`movement.md`; the file says 20 and 40).
5. The objects of hotspots `*U05_05` (the dog) and `*U04_04` (Mazout), with their
   children and siblings, leave collision.
6. `Box17` (or the first object containing that name) becomes unpickable.
7. Talkers `U05_02` and `U04_04`, both with face `$$$DUMMY.*visage`.
8. If M09 is done, `ColPorte2` leaves collision; if M11 is done, `ColPorte1` does.
9. **New entry only** (`a` = 1):
   - The dog's node `*U05_05`: slot 0 disabled; clip `ChienTourne`
     (`Anim/U05_05/Attente.A3D`, 1..356) in slot 1, active, looping, 15 fps, **paused**
     at frame 245.
   - Mazout's node `*U04_04`: clip `MazoutAttente` (`Anim/U04_04/Attente.A3D`, 1..100)
     in slot 1, active, looping, 15 fps, running.
   - Camera cut: eye (−47.6, 77.27, 45.89), yaw −6.31, pitch π/2.
   - Autosave to slot 0 under message 1003 ("Automatic save"), as in `u02.md`.
10. Start the unit ambient `s4_01a` (group 1, looping; 34.3 s).

No suspend, talk or video: the player walks at once.

## Every frame (`U05_UpdateFrameLogic`, E-0362)

The checks run **before** the frame is rendered (`Scene_RenderFrame` is the hook's last
call), in this order:

1. **The dog's routine**, while M01 is done and M06 is not. If `timer` = 0,
   `timer` := now. Then the first that applies:
   - M04 not done: if now > `timer` + 4000, **bark and sit** (below); when it succeeds,
     exhaust M04.
   - M05 not done: **wait loop** (below); on success exhaust M05.
   - Otherwise **the station master notices** (below); on success run M06 (a second time,
     see the note), then if the inventory lacks `U04_44P`, add it.
2. **Mazout**, while M11 is done and M12 is not: **Mazout confronts** (below); on success
   exhaust M12.
3. **The gauge**, while M13 is done and M14 is not: **gauge expiry** (below).
4. While M19 is done and M23 is not: if the eye is within 220 of `*U05_02`'s local
   position, run M23 (cursor 5 on the station master, `Say(U05_02, U05_08)`).
5. **Chatter**, while M24 is done and M25 is not: if `timer` = 0, `timer` := now; if the
   voice group is silent, now ≥ `timer` + 20000 and the eye is within 220 of `*U05_02`:
   `timer` := now; run M26 (`U05_10`) if fmod(rand, 2) = 1, else M27 (`U05_11`).
   M25 is never run, so this lasts until the exit.
6. **The exit**, while M24 is done and `leaving` = 0 (below).
7. **Barks**, while M10 is done: if `barkAt` = 0, `barkAt` := now + 28000; when now >
   `barkAt`: run M82 (effect `d4_12` at the dog), `barkAt` := now + ⌊rand · 40000 /
   32767⌋. Nothing runs or exhausts M10, so this never happens (E-0365).

Distances are 3-D (`FUN_00415e40`).

**Bark and sit** (`U05_DogBarkThenSit`): the dog node's active slot: loop := off. If it
is still running, fail. Else run M82 (effect `d4_12` at the dog, 2.6 s); clip
`ChienAttente` (`Anim/U05_05/ACTION01.A3D`, 0..110) in slot 2, active, not looping,
15 fps, running; succeed. (The looping `ChienTourne` finishes its cycle first.)

**Wait loop** (`U05_DogWaitLoop`): active slot loop := off; if running, fail. Else clip
`Attente2` (`Anim/U05_05/ATTENTE02.A3D`, 1..100) in slot 3, active, looping, 15 fps,
running; succeed.

**The station master notices** (`U05_ChefNoticesDog`): fail while the voice group plays
or the eye is farther than 220 from `*U05_02`. Else run M06 (cursor 3 on `*U05_02`,
`Say(U05_02, U05_04)`, op 14 M08: cursor 5 on the dog), M07's condition := `TRUE`, M09's
condition := `TRUE`; succeed. The frame hook then runs M06 again in the same frame: the
cursor is set again, `Say` restarts `U05_04` from its start (`Talkers_Say` stops the
current talker first) and op 14 M08 does nothing (M08 is done). So the line plays once.

**Mazout confronts** (`U05_MazoutConfronts`): fail unless eye.x < 1425. Suspend.
`WalkPath(4000, (1306.35, −945.6, eye.z), facing *U04_04 from there, π/2)`. Clip
`MazoutA01` (`Anim/U04_04/Action01.A3D`, 1..40) in slot 2 of Mazout, active, not looping,
15 fps, running. Run M13 (`Say(U04_04, U05_07)`, 34.5 s). `RunFor(0)` while the voice
group plays and Enter is not held; stop the voice emitter. **Start the gauge: 15 s,
visible** (`u01.md` gauge). `timer` := 0. Resume.

**Gauge expiry** (`U05_MazoutGaugeExpired`), when the gauge fires (`FUN_0041a6c0(1)`):
clip `MazoutA03` (`Anim/U04_04/Action02.A3D`, 1..50; the name is reused below) in slot 3
of Mazout, active, not looping, 15 fps, running. Hide every object of the scene, then show
Mazout's object (with its subtree). Eye := (1310, −986, eye.z); turn the view from there
toward Mazout's local position + (0, 0, 30) (`FUN_00419580`). Effect `s4_04.wav` at the
eye. `RunFor(0)` until the clip pauses. Fade to black over 2000 ms, then game over
(`OptionLoad`, as `u02.md`).

**The exit** (`U05_ExitToU06`): only when eye.y > 928. Suspend. `WalkPath(7000,
(1096, 1173, eye.z), facing (1266, 1302, z of *U05_13) from there, π/2)`. `leaving` := 1.
Fade to black over 2000 ms. Go to unit 6 (`U06.x3d`, app mode 1; as `u02.md`'s unit 3).
No video.

## The chain

1. Click the station master (M01): he talks (`U05_01`) while the player walks 10 s to
   him; the dog appears, turning.
2. Four seconds later, once its turn ends, the dog barks and sits, then idles. Standing
   within 220 of the station master (with no voice playing), he says `U05_04`; the dog's
   cursor becomes 5 and `U04_44P` is added if missing (the item from U04's M32).
3. Give `U04_44` to the dog (M09): it goes through the hall door (`ChienVersPorte`);
   `ColPorte2` opens the way.
4. Click the grate `*U05_07` (M11, possible from the start): the player goes under it
   and comes up facing −1.55; the station master and the dog are hidden; `ColPorte1`
   opens.
5. Walking west of x = 1425 triggers Mazout (M13 said, 34.5 s): **15 s** to click the lamp
   `*U05_08` (M15), or game over.
6. The lamp falls; the key `*U05_09` appears. Take it (M16), open the left-luggage door
   with it (M17), take `*U05_11` (M19): the station master and the dog are back.
7. Near the station master he says `U05_08` (M23). Give him `U05_11` (M24): he says
   `U05_09`, the handcart `*U05_13` appears, and from then on he chats every 20 s.
8. Walk north past y = 928: the player is walked to (1096, 1173) and U06 starts.

Optional: the paintings (M02, M03), the chair `*U05_12` opening the hall door (M22,
after M13), closing the locker (M81), the dog's bark (M82), the hall door rattle (M83).

## Engine notes

- The timers are GetTickCount deltas; run them in logic time. Nothing is saved, so a
  restore restarts them. A restore does not re-add the start clips, but `ANIMATIONS`
  re-creates every slot clip the dog and Mazout had at save time, with its state and the
  active slot (E-0535).
- The camera numbers are world units and radians; nothing depends on the 4:3 frame
  except the painting frame.
- Missing primitives: a general `WalkPath` (yaw/pitch interpolation, optional ground
  snap; `U02::walkPath` snaps and keeps the angles), `Interaction` "exhaust without
  running", collision off for an object with its children **and siblings**, hiding every
  object and hiding one object without its children, a shared gauge with stop and expiry
  (U02 has its own), the `TableauJeu` frame, and a "turn view to object" snap (or
  `lookAt(0)` on the object's local position). The frame hook runs before rendering,
  `Unit::afterFrame` after: a one-frame shift.
