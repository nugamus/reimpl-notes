# U04: Monet's garden at Giverny

Everything U04's unit code (`U04.cpp`, vtable `0x00439630`, E-0075, E-0330) does on top of
the generic scene: the load-time fix-ups, the entry from U03, the per-frame hooks (the
door timer, Monet's painting timer, the kidnapping, Ernest, the sinking boat), the input
hook (the boat, the window, the exit), the hover hook, the sixteen click handlers, and
the exit to U05. Conventions are those of `u02.md`: `RunFor`, `MoveTo` (100.0 = keep),
`LookAt`, slots, cursor kinds, `Say(character, line)`, "effect X at P" (effects emitter,
group 3), "voice X at P" (voice emitter, group 2), **suspend** / **resume**, `Mnn` = the
INFOACT record with id nn (`infoact.py --file Data/U04/INFOACT.BIN`), "Mnn exhausted",
"Mnn count", "Mnn := TRUE/FALSE" (its condition). "Show X" / "hide X" are the hotspot's
show and hide (E-0272). "Wait for the voice" = `RunFor(0)` while the voice group plays;
"(or Enter)" = also stop when Enter is held.

`s` = 10 (`SCENE.BIN`: ambient 255/255/255, scale 10, FOV 90, `#CAMERA#` 20/40,
overridden at start). On the boat `s` is 20 (below). The eye height stays 1.5·s = 15 at
the start pose.

## Scripts (E-0330)

`Data/U04/` has three scene scripts; only `U04.x3d` is U04's.

- `U04.x3d`: the unit scene. The "go to unit 4" call (`u01.md`) builds `U04.x3d`; U03's
  exit and a restore in U04 load it.
- `U04D.X3D`: a backdrop of the painting gallery, loaded as unit class 50 (not U04's code)
  for paintings `U13_01`, `U13_03`..`U13_06`, `U13_11`..`U13_14` (E-0037). It is
  `U04.x3d` without Monet, the studio furniture (`Salon`, `Chaise`, `U04_37`,
  `PinssoPalette`, `ColTable04`), the chest, the bee, the boat, the door animation and
  the tube, glass and fishing rod; `COLBARQUE.O3D` instead of `CANNAPECHE.O3D`; more pots.
- `U04Cpl.x3d`: named by no binary. `U04.x3d` with the commented-out vegetation back
  (`irisdevant`, `arbrefond`, `arbustefond`, `plantelac1..6`, `plante1..4`,
  `plantelacdevant1`, `chevaletpetit`) and without `ColTable04`: a fuller draft. The
  engine ignores it.

## Load and start (`U04_StartUnit`, E-0331)

U03's exit loads U04 with `a` = 1; a restore uses `a` = 0. Unit vtable `+0x10` is the
generic load; U04 has no load hook. Start (vtable `+0x14`):

1. Game unit number := 4. Unit ambient `s3_01` (group 1, looping).
2. `U04_FixObjectNames` (u00.md step 0, E-0230).
3. `window` := object `Box70`.
4. Generic start: INFOOBJ, INFOACT (`interaction.md`).
5. Collision sphere radius 5.0, Z offset 0.0.
6. `hiddenPick[0]` := `*U04_43`'s object unless M30 is exhausted; `hiddenPick[1]` :=
   `*U04_52`'s object unless M38 is exhausted.
7. If M03 exhausted and M17 not: start the **studio emitter**; if M03 exhausted and M05
   not: start the **bee emitter** (below).
8. If `onBoat`: eye z := the boat hotspot's z + 10 (x, y kept); `s` := 20.
9. Register talker `U04_03` (face `$$$DUMMY.*visage`, clips from `Anim/U04_03/`).
10. If M18 exhausted and M20 not: Monet's face map := `teteBA` (gagged).
11. If `painted`: hide object `pain_Sot01`. If M18 exhausted: hide `kokliko01` if present.
12. (Restore: stop here.) Add `U01_04P` and `U03_06P` to the inventory if missing. Camera
    := (−33.566, 352.43, 15), yaw 1.36, pitch π/2 (a cut). Autosave to slot 0 under
    message 1003 ("Automatic save"), as U02.

**Studio emitter** (`U04_StartStudioEmitter`): a fifth emitter, group 5, range 50·s, plays
`Sound/s3_07.wav` looping at (165.82, 332.92, 15). **Bee emitter**
(`U04_StartBeeEmitter`): a fourth emitter, group 4, range 50·s, plays `Sound/s3_05.wav`

**Face map** (`U04_SetMonetFaceMap(gagged)`): Monet's `TETE` (child search, contains),
its first material's map is replaced by a new map `teteBA.dmf` (gagged) or `tete.dmf`,

## Every frame (`U04_UpdateFrameLogic`, E-0333)

Render and present, then. While the gauge runs, each label fires once (`u01.md` gauge):

1. **"Door"** fired and M03 not exhausted (the door closes on the player): Monet's slot 1
   backward, running, 10 fps; the door node backward, running; `RunFor(0)` + input hook
   until the door node pauses; can move := 1; M02 := TRUE.
2. **"Paint"** fired, M17 not exhausted and eye x > 180, y > 275 (in the studio): **Monet
   finishes painting** (below). The fire test comes last in the condition, so outside
   the studio the gauge keeps waiting and fires when the player walks in.
3. **"ecroule"** fired and `onBoat`: **the boat sinks** (below).
4. **"PlusVite"** fired: voice `d3_20` at eye − (10·s, 0, 0).

Then, gauge or not:

5. **Kidnapping**: M17 exhausted, M18 not, eye y < 40: `U04_AuSecours` (below).
6. **Ernest**: M18 exhausted, M20 and M40 not, eye within 2·s of (213.47, 296.4, 15):
   `U04_ErnestLocksStudio` (below).
7. **Step onto the boat**: not `onBoat` and the ground object is named `*U04_32`
   (case-insensitive): `U04_StepOntoBoat`.

## Input hook (`U04_HandleInput`, E-0333)

Keys are the held-key table (`movement.md`). Not on the boat:

1. **Jump through the window**: M24 exhausted, Shift held, eye within 0.5·s of
   (191, 240.8, 15) and yaw (normalised to [0, 2π)) within 1.5 of 1.54: climb out
   (below); end the hook.
2. **Exit**: M32 and M39 exhausted, Up held, eye x < −22, y > 307, yaw within 1.5 of 4.9:
   leave U04 (below); end the hook.

On the boat:

- Up held: row forward; Down held: row backward (below); end the hook.
- Shift held: take the boat node's slot 1 (or the node if none). If its frame < 60 or >
  last − 60 (near either end of the trip): jump off, frame := 1.0, end the hook. Else, with
  no slot 1: jump off, end the hook. Else (mid-pond with a clip): nothing.

Then, always: if the ground object is `window` (`Box70`): climb out. Generic input
(`Scene_HandleInput`).

## Hover hook (`U04_PickHoverHiddenTargets`, E-0333)

Vtable `+0x44`: unhide every non-null `hiddenPick` object, run the generic hover pick,
hide them again. So the hidden `*U04_43` (the hole) and `*U04_52` (the ladder place) are
pickable but never drawn, until `UseBouchon` / `UseEchelle` drop them from the list.
