# U07: the cellars under the orangery, and the end of the game

Everything U07's unit code (`U07.cpp`, vtable `0x004397d0`, E-0394) does on top of the
generic scene: the load-time renames, the ladder in the drain shaft, the light switch and
the 270-s dynamite gauge, the tipping plank and the water, the two secret walls, the grille,
cutting the fuse, and the end of the game. Conventions are those of `u01.md`, `u02.md`
and `u06.md`.

`s` = 35 (`SCENE.BIN`: ambient 255/255/255, scale 35, FOV 90, sphere radius 20, Z offset
40; E-0398), eye height h = 52.5.

## Load-time renames (`U07_OnLoadRenames`, E-0394)

Unit vtable `+0x10`, after the generic load, before INFOOBJ:

1. Each object named `Object04`, in lookup order: the first becomes `*U06_260`, the second
   `*U06_26`, the i-th (i ≥ 2, counting from 0) `*U06_26` + i. U07 loads two
   (`Static/Cave2.O3d`, `Static/Chambre1.O3d`); with the newest-first list (`u01.md`) the
   dynamite hotspot `*U06_26` is `Cave2`'s (Q-0174).
2. `secretpioc` → `*U06_28`; the first `*U06_27` found → `*U06_29` (the `Cave2` wall, loaded
   after the grille's file, so the grille keeps `*U06_27`).
3. Every object whose name starts with `halo` (case-sensitive, 4 characters): no collision.
4. The parent of the object `planche` is renamed `*U06_30`.

## Entry (`U07_StartUnit`, E-0394)

U06's `UseBiche` loads U07 with `a` = 1; a restore uses `a` = 0.

1. Start the unit ambient `s4_16` (group 1, looping; 14.9 s). Landing sound off (camera
   `+0x58` = 0: falls stay silent).
2. Generic start: INFOOBJ, INFOACT.
3. If M07 is not exhausted: emitter A (group 4, range 50 · s) plays `Sound/s4_22.wav`
   looping at (1299, −143, 473). Emitter B (group 5, range 50 · s) plays
   `Sound/s4_19.wav` looping at (1536, 363, 374).
4. Sphere radius := s / 4 (8.75); sphere Z offset := 0.4 · h (21).
5. Ground object := `*U06_30`'s object (so the water check below does not fire before the
   first ground probe).
6. If M04 is exhausted (the grille is open): `ColGrille` no collision.
7. (Restore: stop here.) Camera cut to (1454.67, 1912.72, 570.605), yaw 1.04, pitch 2.77
   (looking down the shaft). Can move := 0, collision off.
8. If the inventory holds `U06_19P.bmp` (the item from U06): hide `*U06_19` (no
   collision).
9. **Autosave** to slot 0 as "Automatic save".

Leaving the unit (vtable `+0x18`, `U07_DeleteEmittersAndUnload`) deletes emitters A and B,
then runs the generic unload.

## Every frame (`U07_UpdateFrameLogic`, E-0397)

After the generic render: if the gauge has just expired, **the explosion**.

### The explosion (`U07_DynamiteExplodes`)

1. Suspend. Stop and delete emitter A.
2. Cut to (1390.44, −120.8, 487.27), yaw 9.16, pitch π/2. Effect `Explosion` at the eye
   (4.95 s).
3. For 2000 ms of wall clock: `MoveTo(100, keep, keep, keep, FOV f)`, f alternating 70,
   90, 70, …; whenever more than 100 ms passed since the last change (the first pass
   always): r = ⌊rand · 5 / 32767⌋, ambient := r 1 (255, 0, 0), 2 (128, 0, 255),
   3 (128, 255, 0), 4 (255, 255, 255), else (0, 0, 0); then one call of the frame hook
   (render; the gauge does not fire twice).
4. Fade to black over 2000 ms; game over (`OptionLoad`).

## Input hook (`U07_HandleLadderAndGround`, E-0395)

The generic input first. Then:

**While M01 is not exhausted (the ladder)**: the player cannot walk (step 7) but can turn.
- Up flag set: p = eye + (0, 0, 20); if there is headroom at p (`HasHeadroom`: the lowest
  hit straight up is at least 0.4 · s above p), `MoveTo(1200, p)`. Clear the Up flag.
- Down flag set: p = eye − (0, 0, 20); if p's height above the ground below it ≥ h,
  `MoveTo(1200, p)`. Clear the Down flag.

The flags are the key-held flags of `movement.md`; clearing them makes each key-down
message one 20-unit rung (Windows' key repeat gives more while held).

**Once M01 is exhausted**:
- If not `plankTipped` and the ground object is named `Planch01` (case-insensitive):
  **the plank tips**.
- Then, if there is no ground object or its name starts with `*eau` (case-sensitive):
  **into the water**.

### The plank tips (`U07_TipPlank`)

1. Suspend. `plankTipped` := 1.
2. `MoveTo(800, (1034.62, 287.2, 374), yaw 7.863, pitch 1.0108)`;
   `MoveTo(1000, (1034.55, 284.2, 374.3), yaw 4.743, pitch 0.85)`.
3. Load `Anim/planche.A3D`, rename its root animation `*U06_30`, and bind it to the
   `*U06_30` hotspot's object as a new node at 30 fps (one node, the root name has a `*`;
   `animation.md` "Binding"). That node: enabled, loop off. Effect `planche` at the eye.
   `RunFor(0)` until the node pauses (50 frames, 1.6 s).
4. `MoveTo(1000, keep, keep yaw, pitch π/2)`. Resume.

### Into the water (`U07_FallInWater`)

As U02's fall without the dimming: suspend; effect `eau` at the eye; d = unit vector of
the camera's yaw and pitch; P = (eye.x + s d.x, eye.y + s d.y, eye.z − h + 10); collision
off; fall to P (`movement.md` "fall"); `MoveTo(800, P, keep, pitch 0.5, FOV 40)`;
`MoveTo(600, keep, yaw + 3)` twice; fade to black over 2000 ms; game over.

## Click handlers (E-0396)

The dispatcher (`0x004119d0`) compares, in order, `DoInterrupteur`, `Open1Secret`,
`Open2Secret`, `CouperDynamite`, `OpenGrille`. No post-queue check. M02's `xxx` (trigger 0,
never triggered) has no handler.

| Handler | Action (steps before it) | Does |
|---|---|---|
| `DoInterrupteur` | M01, click the switch `*U06_22` | The switch and the descent, below. |
| `OpenGrille` | M04, click `*U06_27` (node `*U06_27` runs, `s4_20` at the hotspot) | `ColGrille`: no collision. |
| `Open1Secret` | M05, use `U06_24` on `*U06_28` (pickaxe kept) | Effect `s4_21` at the eye; hide `*U06_28` (no collision); `mursecret` no collision. |
| `Open2Secret` | M06, use `U06_24` on `*U06_29` | Effect `s4_21` at the eye; hide `*U06_29` (no collision); use up the held item (Q-0173); `mursecreth` no collision. |
| `CouperDynamite` | M07, use `U06_19` on `*U06_26` | The end of the game, below. |

M03 (take the pickaxe `*U06_24`) and M08 (take `*U06_19`) are steps only.

### The switch and the descent (`DoInterrupteur`)

1. Suspend. Switch node `*U06_22` running. Effect `s1_08bis` at the eye; `RunFor(0)` while
   the effects group plays (1.6 s).
2. Lamp node `*Eteint01` running (frame 8 to 10 at 1 fps). Effect `s4_20` at the eye.
   `MoveTo(1000, keep, yaw 4.64, pitch 0.3)`; `RunFor(0)` until the lamp node pauses.
3. **Start the gauge: 270 s, visible** (`u01.md` gauge; no warning line).
4. `MoveTo(1000, keep, yaw 1.54286, pitch 0.530796)`.
5. Q = eye. Repeat: Q.z := eye.z − 0.6 · s (21); `MoveTo(1000, Q)`; `RunFor(300)`; until
   the eye's height above the ground below it is less than 1.8 · h (94.5).
6. Snap to the ground (`Camera_FollowGround`: a fall if higher than 1.3 · h, silent).
   If `<data root>/SAUT.WAV` exists, play it on the effects emitter at the eye.
7. `MoveTo(800, keep, keep yaw, pitch π/2)`; `MoveTo(1500, (1453.19, 1912.76, 362.294),
   yaw 2.663)`.
8. Collision on, can move := 1. Resume.

### The end (`CouperDynamite`)

1. Stop the gauge. Use up the held item (Q-0173). Hide `*U06_26` (no collision).
2. Stop and delete emitter A (the fuse).
3. `RunFor(3000)` (not suspended).
4. Play `Video/Epilogue.avi` (IV50, 640×480, 10 fps, 362 frames, 36.2 s) with
   `Video/epilogue.wav` (37.0 s) as in `boot.md`; stop the voice group afterwards; no
   scene redraw.
5. Open the Option menu (frame manager `+0xc0(0)`, as `SelectUser` for a known player,
   `ui.md`). No credits, no further unit: this is the end of the game (E-0399).

## INFOACT (E-0398)

`Data/U07/INFOACT.BIN`, ids 1..8, all `TRUE`, each once. M01 click `*U06_22` →
`DoInterrupteur`; M02 trigger 0 → `xxx` (dead); M03 take `*U06_24`; M04 click `*U06_27` →
op 4 `*U06_27`, op 13 `s4_20`, `OpenGrille`; M05 use `U06_24` on `*U06_28` →
`Open1Secret`; M06 use `U06_24` on `*U06_29` → `Open2Secret`; M07 use `U06_19` on
`*U06_26` → `CouperDynamite`; M08 take `*U06_19`. INFOOBJ: 11 hotspots, all visible.

Goal chain: climb down the shaft (Up/Down), flip the switch (the dynamite's 270-s gauge
starts and the player is lowered to the floor), cross by the plank (it tips; stepping into
the water is fatal), take the pickaxe, break the two secret walls, open the grille, and cut
the dynamite's fuse with `U06_19` (brought from U06, or taken here) before the gauge runs
out.

## Engine notes

- Run the gauge and the explosion's 2000 ms in logic time; the colour flicker picks a new
  colour every 100 ms.
- The ladder steps are per key press: consume the press in the input hook.
- The plank's clip is loaded at run time and bound to an existing object.
