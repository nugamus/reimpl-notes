# U02: the level crossing and the ticket office

Everything U02's unit code (`U02.cpp`, vtable `0x00439468`, E-0075) does on top of the
generic scene: load-time renames, the entry from U01, the per-frame hooks (falling into the
stream, the chestnut seller's calls, the magpie, the 3-minute train gauge), the sixteen
click handlers, and the exit to U03. Conventions are those of `u01.md`: `RunFor`, `MoveTo`
(100.0 = keep), `LookAt`, "run node to f", slots, cursor kinds, `Say(character, line)`,
"effect X at P" (effects emitter, group 3), "voice X at P" (voice emitter, group 2),
**suspend** / **resume**, `Mnn` = the INFOACT record with id nn
(`infoact.py --file Data/U02/INFOACT.BIN`), "Mnn exhausted", "Mnn count" (its run count,
already incremented when the handler runs). "Hotspot position" = the hotspot object's
global position (hotspot `+0x70`), as in U01. "Show X" is the hotspot's show: unhide and
back into collision; "hide X (no collision)" the reverse (E-0272). Hotspots hidden by
INFOOBJ start out of collision (`interaction.md`).

`s` = 40 (`SCENE.BIN`: ambient 255/255/255, FOV 90, sphere radius 20, Z offset 40; E-0165).
U02 has no input hook of its own: vtable `+0x40` is the generic `Scene_HandleInput`
(E-0160), so walking and the keys are exactly `movement.md`'s.

**Camera path** `WalkPath(ms, target)` (`FUN_00419620`, E-0161): N = ⌊ms · fps / 1000⌋
steps (at least 1); each step moves the eye by (target − start) / N, then snaps it to the
ground (`Camera_FollowGround`, `movement.md` "Ground"), ticks, renders and updates the
emitters; yaw and pitch stay; finally the eye := target. No collision.

## Entry (`U02_StartUnit`, E-0160)

U01's exit (`u01.md` "Leaving U01") loads U02 with `a` = 1; a restore uses `a` = 0.

1. Generic start: INFOOBJ, INFOACT (`interaction.md`).
2. Register talkers `U02_02`, `U02_03`, `U02_04` (faces above).
3. If M08 is exhausted and M12 is not (the clerk is asleep): effect `d1_25` looping at
   `*U02_04`'s hotspot position (his snore; only reachable on a restore).
4. If the `*U02_01` hotspot's object is hidden, make it unpickable (`+0x114`).
5. (Restore: stop here.) Camera := (122.626, 67.0605, 52.529), yaw 0.1, pitch π/2 (a cut;
   FOV and the rest are the camera defaults of `movement.md`).
6. If the inventory lacks `U02_01P` (the 100 F coin), add it.
7. **Autosave**: save the game to slot 0 under the name of message 1003 of
   `Message.txt` (next to the EXE): "Automatic save" (E-0160).

No suspend, no talk, no video: the player can walk at once.

## Every frame (E-0161)

Order: animation tick, render and present (the gauge is drawn as in `u01.md`), then:

1. **Fall into the stream**: if the camera's ground object is named `*U02_08`
   (case-insensitive), run **the fall** (below).
2. **The seller's calls**: if not `callOff`, now − `callStart` > `callPeriod` and the voice
   group is silent: `callStart` := now; r = ⌊rand · 3 / 32767⌋;
   `Say(U02_03, r = 1 ? d1_12 : r = 2 ? d1_13 : d1_14)`.
3. **The magpie waits**: if `magpie` = 1 and the eye is within 240 of (1280, −564, −7.15):
   suspend; `magpie` := 2; `pieClip` := `*U02_05`'s slot named `PieVoleur` if not set;
   set it running; `LookAt(400, pieClip's object)`; d = the unit view direction;
   `WalkPath(1000, eye + (150 d.x, 150 d.y, 0))`; effect `S1_17` at the eye; while its
   frame < 240, `LookAt(0, pieClip's object)` (the view follows the bird); `*U02_05`
   cursor := 5; resume.
4. **The train gauge** (started by `MarronToPie`, 180 s): while it runs, once per process
   when 160 s < elapsed < 170 s: `warned` := true, `Say(U02_02, d1_26)`. When it
   expires: suspend; effect `s1_22` at the eye (the train leaves); `Say(U02_02, d1_27)`;
   `RunFor(0)` while the voice or effects group plays; then game over as U01's "caught"
   step 8: stop every sound, open `OptionLoad` (app mode 2).

### The fall (`U02_FallInStream`, E-0161)

1. Suspend. Effect `s1_19` at the eye (10.1 s).
2. N = ⌊fps⌋ steps: each step sets every ambient channel c := trunc(c − (c₀ − 90) / N)
   (float step, 0 if below 0), applies it, `RunFor(10)`. The truncation loses ⌈step⌉ a
   step, so 255 ends at 255 − N·⌈165/N⌉: 75 at 30 or 60 fps, 90 only when N divides 165
   (E-0275). About a second.
3. d = unit vector from the camera's yaw and pitch; P = (eye.x + s d.x, eye.y + s d.y,
   eye.z − (h − 30)), h = eye height (60).
4. Collision off. Fall (`movement.md` "fall": z = z₀ − 5.9 s t², x and y kept) by
   D = |P − eye| (the 3-D distance, so it drops a little below P.z; landing sound if
   D > 1.5 s).
5. `MoveTo(800, P, keep, pitch 0.5, FOV 40)`; `MoveTo(600, keep, yaw + 3)` twice (a spin,
   yaw read again before each).
6. Fade to black over 2000 ms (as U01's "caught" step 7), then game over (`OptionLoad`).

## INFOACT (E-0165)

`Data/U02/INFOACT.BIN`, ids 1..8 and 12..21 (none 9..11). Steps other than op 10:

So the intended chain: give the 100 F coin to the clerk (refused, take it back), buy
chestnuts, take the bag (the seller's change is stolen by the magpie), walk up to the
magpie, give it a chestnut (it drops the coin `U02_09` and the 3-minute gauge starts, the
clerk dozes), take the coin, ring the bell, buy the ticket, take it, give it to the
inspector. The plank bridges the stream on the way; the door `*U02_12` is optional.

## Engine notes

- Run the call timer, the gauge and the magpie proximity test in logic time; save
  `callStart` as "ms since the last reset", not a clock value (Q-0092).
- The gauge is the `u01.md` gauge with 180 s; draw it the same way.
- The camera values above are world units and radians independent of the aspect ratio;
  only the FOV-60 zoom in `Sonner` assumes the 4:3 frame's horizontal FOV.
