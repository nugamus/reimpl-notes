# U01: the station

Everything U01's unit code (`U01.cpp`, vtable `0x004393d0`, E-0075) does on top of the
generic scene: load-time fixes, the scripted entry, the per-frame escape timer, riding the
train, the twelve click handlers, and the exit to U02. Helpers are specified elsewhere and
only referenced here:

- `RunFor(ms)`, `MoveTo(ms, position, yaw, pitch, fov)` (100.0 = keep; no position = keep),
  `LookAt(ms, object)`, walking, collision and the ground object: `movement.md`.
- Animation nodes, frames, stop targets, sub-slots: `animation.md`. "Run node to f" below
  means: set the node running with stop target f (it pauses on reaching it, or at the end of
  a non-looping animation); "set frame f" clamps f to the animation's range.
- Hotspots, cursor kinds (0 default, 2 click, 3 talk, 4 take, 5 use), actions, steps and
  the unit queue: `interaction.md`.
- Sound groups and emitters, `Say(character, line)` with lip sync, "the voice plays":
  `sound.md`. "Effect X at P" = the effects emitter (group 3) plays `Sound/X` at P; "voice
  X at P" = the voice emitter (group 2).

`s` is the scene scale (40). **Suspend** = hide the cursor and ignore camera keys and clicks
(app `+0x480` = 1); **resume** undoes it (`FUN_00414820`, E-0081). Action `Mnn` is the
INFOACT record with id nn (`infoact.py --file Data/U01/INFOACT.BIN`); "Mnn exhausted" is
the flag of `interaction.md` "Run".

## Unit state (E-0080, E-0081)

| Name | Meaning | Initial |
|---|---|---|
| `switchThrown` | the points (`*U01_21`, lever `Aiguille02`) are set for the siding | `*U01_21` node frame ≥ 2 at start (INFOOBJ: 1 → false) |
| `trainNode` | the node that moves the train: `*U01_20`'s active slot | `*U01_20` (`U01_20.A3D`, frames 1..270, 15 fps, looping, paused at 20) |
| `train2Loaded` | the siding clip has replaced it | false; saved |
| `onTrain` | the ground object under the eye is the train | false; saved |
| `firstMaire` | `ClickMaire` not yet used | true (process-wide, not saved) |
| gauge | the 20-second escape timer (below) | stopped |

Saves store `train2Loaded` and `onTrain` as two u32 in chunk `TRAIN_CHANGED` (E-0080). A
restore does not reload the siding clip.

## Load-time fixes (E-0080)

After the `.X3D` is loaded and before INFOOBJ is applied (unit vtable `+0x10`):

1. The first object named `Box31` is renamed `*U01_21`, and the animation node `Object07`
   (from `U01_21.A3D`) is renamed `*U01_21`: the switch hotspot and its animation.
2. While an object named `Box20` exists, rename it `Box201`, `Box202`, … in lookup order.
3. `Box203`: hidden, no collision, not pickable (object `+0x118` and `+0x114`); `Cylinder07`
   hidden (E-0060).
4. `tige` is renamed `*U01_12`; `*U01_08P` is renamed `*U01_08`.

Lookup order is X3D's top-level object list, which is newest first (each load prepends).
With U01.X3D's file order that makes `Box201` = PLDV's, `Box202` = RAILS', `Box203` =
INTCAB's, `Box204` = PTITRAIN's `Box20`, and `Box31` = the one in `U01_21.O3D` (E-0530).

## Entry (`U01_Start`, E-0081)

With `a` = 1 (new game; `a` = 0 is a save restore):

1. Play `Video/Prologue` (`boot.md`). (Restore: skip this.)
2. Collision sphere Z offset := 37.0. Load INFOOBJ/INFOACT (`interaction.md`).
3. Register talkers `U01_01` (face `$$$DUMMY.*01SParle`) and `U01_02` (face
   `$$$DUMMY.*02SParle`) (`sound.md` "Talkers").
4. Initialise the unit state above. If `onTrain` (restore), the camera's ground object is
   the train. `*Ernest`'s object and its subtree lose collision. `Tapiroug*` (the red
   carpet) is made unpickable (`+0x114`, E-0070).
5. Start the unit ambient `U01` (`sound.md`). (Restore: stop here.)
6. Suspend. Cursor kinds of `*U01_02` and `*U01_01` := 0. If the inventory lacks item
   `U02_01P`, add it (Q-0046).
7. Camera: (−258.44, −508.20, 29.546), yaw 1.31, pitch π/2 (E-0041). `RunFor(1500)`.
8. Actions disabled; Escape disallowed.
9. `Say(U01_01, d1_01)` (23.4 s, no lip file).
10. `LookAt(1000, TETE)`: the first object named `TETE` (case-insensitive) depth first under
    `*U01_01`'s object.
11. `MoveTo(2500, (−405.67, −494.31, 29.5), 2.9)`; `MoveTo(800, (−468.4, −481.3, 29.5), 1.76)`.
12. Wait while the voice plays; Enter held ends the wait. `RunFor(1000)`.
13. Run M01's steps (as a click would, and count the run: M01 is then exhausted): effect
    `Marsaillaise` at `*U01_02`, `Say(U01_02, d1_02)`.
14. Start node `*U01_03` (the crank). `LookAt(1000, TETE under *U01_02)`. `RunFor(400)`.
    Remember the FOV.
15. `MoveTo(1400, (−466.36, −452.495, 30.48), 4.7)`; `MoveTo(1800, same, 4.7, pitch 1.4908,
    FOV 45)`.
16. Wait while a character talks (the scene's current talker is set, i.e. `d1_02`); Enter
    held ends the wait. This is the wait E-0050 calls "camera animation".
17. Stop the effects and voice groups. Pause `*U01_03`.
18. `MoveTo(600, keep, keep, π/2, remembered FOV)`.
19. `GiveCard` (`animation.md`: `Anim/U01_02/Action03.A3D` in slot 1 of `*U01_02`, once).
20. Can move := 0, can turn := 0. Escape allowed. `*U01_01` cursor := 3. Actions enabled.
    Resume.

Only `TakeCard` (below) enables walking. Without Enter the entry lasts about 1.5 + 23.4 +
1 + 41.6 + 0.6 s (the two talks dominate; camera moves overlap them), plus the voice
group's early end of `sound.md`.

## Every frame

Order (`movement.md` frame loop): animation tick, then the unit frame: render and present
(drawing the gauge), then the gauge check below; then, unless suspended, the unit input
hook.

### The escape timer (E-0082)

The gauge is started by the phone call (`ClicTel`, below) with 20 s. While running it
counts `timeGetTime` ms and is drawn after the cursor, on top of the frame: a grey
(0x808080) rectangle from (9, 9) to (111, 21) and a red one (0x0000FF passed as a
COLORREF; red is inferred) from (10, 10) to
(110 − ⌊100·p⌋, 20), p = elapsed / 20 s (Windows rectangles, right/bottom exclusive, 640×480
frame coordinates). `MonterSurToit` stops it. When p reaches 1 the gauge stops and U01
plays "caught":

1. Suspend; Space disallowed (app `+0x488` = 0).
2. Effect `S1_10` at the eye; wait while the effects group plays (no skip).
3. Show `*Ernest` (with collision).
4. `LookAt(100, *U01_07's object)` (the door). Door node: set frame 2.0, then `OpenDoor`
   (below).
5. Voice `s1_11` at the eye. Wait until the door node pauses (frame 12).
6. `MoveTo(1000, (486.059, −107.99, 24), 0.0831, 1.95)`; `MoveTo(2000, keep, 0.1631, 2.19,
   FOV 35)`.
7. Fade to black over 2000 ms: N = ⌊2000 · fps / 1000⌋ steps; each step lowers the ambient
   colour by its starting value / N per channel (not below 0) and runs `RunFor(10)`.
   Space is allowed again after.
8. Open the load-game frame (`OptionLoad`, app mode 2) after stopping every sound: the
   player must load a save (E-0082).

### Input hook: riding the train (E-0083)

Replaces the plain camera input:

1. `onTrain` := (camera ground object = `*U01_20`'s object: that object itself, not its
   children and not another object of the same name; the train's part names `Box33`,
   `Cylinder10` also name floor objects, E-0614). If so:
   - collision off; if Up is held (`GetAsyncKeyState`), **ride** (below), else the normal
     keys;
   - ground probe from the eye (updates the ground object only; the position is not
     changed); if no longer on the train, collision on.
2. The generic input (`Scene_HandleInput`: the normal keys, then debug keys), in every
   case. So on the train the keys act twice per frame (turns 0.12 rad), and while riding
   Up also adds one walk step (collision off) to the ride position.
3. If on the train and Up is not held: stop the effects group.

**Ride**, once per frame while Up is held:
1. Advance `trainNode` by one step (frame += dt · fps), even though it is paused; the
   animation tick poses the train from that frame.
2. P = the train object's global position, Q = `*U01_23`'s (a point ahead of it on the same
   animation). Effect `s1_12` looping at the eye if the effects group is silent, else move
   the effects emitter to the eye.
3. Q.z += 10; P.z := Q.z + 18 (before the +10); d = normalize(Q − P). Camera position :=
   (P.x − 40 d.x, P.y − 40 d.y, P.z − 20 d.z); yaw := the direction P → Q; pitch := π/2.
4. **Siding check.** If `train2Loaded`: when `trainNode`'s frame equals its last frame,
   leave U01 (below). Else if `switchThrown` and |⌊frame⌋ − 90| ≤ 1: load
   `Anim/U01_20A.A3D` as clip `Train2` in slot 1 of `*U01_20` (active), bind it to the
   train object's parent with its root animation, 10 fps, not looping, paused; set frame
   15; `trainNode` := it; `train2Loaded` := true. (`U01_20A.A3D`: frames 0..120.)

Without the switch the train loops on its 270-frame circuit (18 s of Up held).

**After the queue** (E-0250): U01's click handler is hover, trigger, drain the queue, then
this check, on every click with a hovered hotspot: if id 20 is exhausted, the hovered
hotspot is `*U01_09` and the eye is below z = 100, run `MonterSurToit` again (resolves

condition `M20`) never runs, because exhaustion is per id (`interaction.md` "Run") and the
first `M20` exhausts id 20. Right after the first climb the eye is at z 139, so the check
does not fire.

## Items and the goal chain (E-0253, E-0251, E-0252)

Every take hides the object and takes it out of collision, puts the item on the cursor and
shows the bar (`interaction.md`); nothing enters the bar until the player clicks the strip,
presses Escape, or the unit changes (a held item goes back to the bar when U01 hands over
to U02, and when "caught" opens the load screen). Using an item up (op 3) removes it for
good.

| Item | Taken | Used |
|---|---|---|
| `U02_01` banknote | given by `U01_Start` | U02 |
| `U01_04` card | M02 from the mayor (`TakeCard`) | U04 (on `*U04_03`) |
| `U01_05` | M07 | M08, door `*U01_07`: `OpenDoor` (used up) |
| `U01_12` rod (`tige`) | M14 | M15, fuse box `*U01_13`: open, cursor 2 (used up) |
| `U01_19` clock card | M18 (`TakeCarteHorloge`: phone cursor 2) | U03 (on `*U03_09`) |
| `U01_08` ladder | M19, only after the call | M20, `*U01_09`: the climb (used up) |

The chain to U02: take the card (walking starts) → take `U01_05`, open the door → take the
rod, open the fuse box, pull the lever `*U01_14` (M16) → take the clock card → click the
phone (M10): with the lever down this is the call (else it rings, and the next click hangs
up) → the gauge runs 20 s → take the ladder, use it on `*U01_09` → throw the points
`*U01_21` (M21, any time, unlimited) → ride the train with the points thrown (Q-0047: how
the roof reaches the train).

### `ClicTel` (E-0085)

The handset node `*U01_11` (`Combine.A3D`, frames 0..62, 15 fps, not looping). With n =
M10's run count, this click included:

- **n even (hang up):** handset backward and running; loop `RunFor(0)` plus the unit
  input hook until it pauses. Stop and delete the ring emitter. Effect `TelGrisi` at the
  phone hotspot.
- **n odd, lever down (M16 exhausted):** phone cursor := 0, M10's condition := `FALSE`,
  then **the call** (below), handset running.
- **n odd, otherwise:** effect `TelGrisi` at the phone hotspot; loop `RunFor(0)` plus the
  input hook while the effects group plays; create a third emitter (group 4, range 50 · s)
  playing `Sound/TelGrisi2.wav` looping at the phone hotspot; handset running.

Then, if n = 1: M04, M05, M06 conditions := `FALSE`; `*U01_01` cursor := 0.

**The call** (`0x00402380`): suspend; handset forward, running. If M24 is not exhausted:
run M24's steps and count them (voice `D1_10` at the phone: 48.2 s), M19's condition :=
`TRUE` (the ladder `*U01_08` can be taken), `MoveTo(1500, (433.788, −91.1468, 24.7812),
2.84318, 1.0708)`, wait while the voice plays (Enter skips), `MoveTo(1000, (421.145,
−69.187, 24.78), 0.6431)`, effect `CloseDoor` at the eye, `CloseDoor` handler, **start the
gauge (20 s, visible)**, `*U01_08` cursor := 4, resume.

### `MonterSurToit`: the climb (E-0086)

Suspend; stop the gauge; show `*U01_10` (the ladder in place). `MoveTo(1000, (439.833,
−50.66, 28.2052), keep, π/2)`; `MoveTo(800, keep, −0.45)`; `RunFor(500)`. With
T = (439.833, −50.66, 100.637) and D = |T − eye| taken once, five times:
`MoveTo(500, (439.833, −50.66, eye.z + D/7))`, `RunFor(200)`. Then `MoveTo(1500, (469.932,
−40.2943, 110.637), 7.2731)`, `MoveTo(1200, (485.775, −44.9, 139))`. Sphere Z offset :=
20. Resume. The eye now stands on the train roof, so the input hook's train mode applies.

### `DoInterrupteur`: the points (E-0086)

Node `*U01_21`: loop off, running. Effect `s1_13` at the eye. Remember the camera position,
yaw and pitch. Views, set directly (no interpolation): A = (667, 723.8, 94), yaw 6.02,
pitch 0.79; B = (753.22, 662.18, 93.55), yaw 6.26, pitch π/2.

- `switchThrown`: node backward, run to 0; `switchThrown` := false; A, `RunFor(1200)`;
  B, `RunFor(1500)`.
- else: `switchThrown` := true; node forward, run to 100 (stops at its last frame, 48);
  `RunFor(600)`; B, `RunFor(1500)`; A, `RunFor(1200)`.

Restore the camera; `RunFor(0)`.

## Leaving U01 (E-0087)

With the points thrown, riding past frame ~90 switches the train to the siding clip; when
that clip reaches frame 120 (Up held, 10 fps: 10.5 s from frame 15):

1. Suspend. Fade to black over 2000 ms (as in "caught"). Space disallowed.
2. Effect `s1_12` looping at the eye (no restart if already playing). Stop group 1 (the
   ambient).
3. For d = 10, 20, … while d < 60 · s: effects emitter distance := d, `RunFor(20)`
   (`sound.md` "Train departure": 4.8 s).
4. Go to unit 2: scene name `U02.x3d`, app mode 1 (`boot.md` "Scene switching"). U01 plays
   no video; what U02's start hook does belongs to U02.

The "go to unit n" call (game object vtable `+4`) builds `U%02d.x3d`, except n = 8 →
`U33.x3D`; it does nothing if a load is already pending.

## Engine notes

- The ride and the siding check run per rendered frame in the original (train speed is
  wall-clock via dt, so frame-rate independent). Run them in the logic tick.
- All camera cuts and moves above are the `movement.md` primitives; the positions assume the
  640×480 4:3 frame only through the FOV, so they hold at any aspect ratio.
- The gauge is in 640×480 frame pixels: scale it with the frame.
