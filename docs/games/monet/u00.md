# U00: the garden with Monet (players screen and tutorial)

Everything U00's unit code (`U00.cpp`, vtable `0x004395d8`, E-0034) does on top of the
generic scene: load, the players screen, the tutorial for a new player, and its end in the
Option menu. U00 is U04's garden: the script is `Data/U00/U00.x3d`, every asset and map
comes from `Data/U04/`, but `SCENE.BIN`, `INFOOBJ.BIN`, `INFOACT.BIN` and the voices come
from `Data/U00/` (E-0200). Helpers (`RunFor`, `MoveTo`, `LookAt`, ground object, jump keys):
`movement.md`; hotspots, actions, cursor modes: `interaction.md`; talkers, groups:
`sound.md`; frames, Escape, Option menu: `ui.md`.

`s` is the scene scale: 10 (`U00/SCENE.BIN` `#SCENE#`; eye height 1.5·s = 15 matches the
start pose). **Start pose** P₀: position (81.1334, 265.81, 15.0), yaw 4.67, pitch 1.47.

"The stone" below (and the function names `U00_StepOntoStone`, `U00_JumpOffStone`) is
`*U04_32`, the top object of `Anim/barke_placement.o3d`: a boat on the pond at about
(141.4, 66.9, −21.8). The glasses to take lie in it (E-0231).

## Unit state (E-0201)

| Name | Meaning | Initial |
|---|---|---|
| `practice` | U00 was entered from the Option menu's Practice | process-wide, false until Practice is chosen, never reset |
| `started` | the tutorial's first frame has run | false |
| `onStone` | the eye is parked on the stone `*U04_32` | false |
| `moved`, `turned` | the player has walked / turned since the hint asked (`moved` is never read) | false |
| `glassesTaken` | the glasses were taken, **or** the state-4 hint has played once | false |
| `nearMonet` | the "come to me" line has played, or the glasses left the cursor | false |
| `spaceSeen` | the ending started (Space never sets it, E-0214) | false |
| gauge | the scene's timer (`u01.md` "The escape timer"), here **hidden** | stopped |

The gauge carries a state number (0 = none) and a label. `Start(state, label)` = run 10 s,
invisible, state and label set; `Stop` = stopped, state 0. When it has run its 10 s it
**fires**: once per frame from then on, until restarted or stopped (U00 checks it without
stopping it). Labels (`deplace`, `Tourner`, `Sauter`, `Take`, `Take2`, empty) have no
visible effect: they are only written to and read from the save chunk `JAUGE` (E-0605).

## Load (`U00_Load`, E-0200)

1. Map directory `U04/Maps/`; load `U00/U00.x3d`; asset root `U04/` from here on.
2. Unit ambient `s3_01` (`U04/Sound/s3_01.wav`, group 1, looping, `sound.md`).

6. Camera to P₀.
7. Unless `practice`: `RunFor(0)`, **Say** `sb01` (below), app mode 2, open frame
   `OptionUser` (`ui.md` "Players screen"). The scene stays paused under it.

## Monet's lines (E-0200)

All voice files are `U00/Sound/<line>.wav`. Two ways to play one:

- **Say**(line, cut): if `cut`, remember the camera's position, yaw, pitch and FOV, and
  put the camera at P₀ with FOV 90. Set Monet's node running, `Say(U04_03, line)`
  (`sound.md`: voice emitter at the face, group 2, lip sync), then run frames (`RunFor(0)`)
  while the voice group plays: **blocking, no skip key** (E-0043). If `cut`, restore the
  remembered camera.
- **Remark**(line): play it non-positionally on group 2 at volume 100, stopping the group
  first (as action op 101). Not waited on; the player keeps control. Monet's node and
  mouth are not touched (E-0231).

Durations (corpus): sb01 3.73 s, sb03 11.88, sb03_bis 13.38, sb04 14.38, sb05 6.62,
sb06 9.98, sb07 9.31, sb08 6.10, sb09 7.21, sb10 6.37, sb11 7.32, sb14 15.76. `sb01b`,
`sb02`, `sb05_b`, `sb11b`, `sb12`, `sb13` are on the CD but named nowhere in the EXE.

## How the tutorial is reached (E-0105, E-0201)

- **New player** (players screen, `SelectUser` with a name not in the list): the frame
  closes, app mode 0, and the tutorial below runs.
- **Known player**: the Option menu opens at once; the tutorial does not run.
- **Practice** (`OptionEntrenement`, `ui.md`): close the menu, set `practice`, load
  `U00.X3D` as a scene switch with "no game started" (game `+0x160` = 0). Start skips
  step 7, so the scene is in app mode 0 at once and the tutorial runs, opening with
  `sb03_bis` instead of `sb03`.

## Every frame (unit frame hook, E-0201)

Render and present, then:

1. **First frame** (`started` false): set it. Say(`sb03`, no cut), or `sb03_bis` when
   `practice`. `Start(1, "deplace")`. Camera to P₀ with FOV 90. Done for this frame.
2. Otherwise, if the gauge fires, by its state:

| State | Needs | Line | Then |
|---:|---|---|---|
| 1 walk | — | Say(`sb04`, cut) | `Start(1, "deplace")` |
| 2 turn | `onStone` | Remark(`sb06`) | `Start(2, "Sauter")` |
| 3 jump | `onStone` | Remark(`sb05`) | `Start(3, "Sauter")` |
| 4 take | `onStone` | Remark(`sb07`) | `glassesTaken` := true; `Start(5, "Take2")` |
| 5 take again | `onStone` | Remark(`sb08`) | `Start(5, "Take2")` |
| 7 store | cursor mode 1 (holding an item) | Remark(`sb09`) | `Start(7, "")` |
| 7 store | not holding, `nearMonet` false | — | `nearMonet` := true; `Stop`; if `onStone`: `Start(3, "")` |
| 8 inventory | `spaceSeen` false | Say(`sb11`, no cut) | `Start(8, "")` |

A row whose "Needs" fails does nothing (the gauge keeps firing). State 6 does not exist;
state 0 does nothing.

## Input hook (E-0201)

Runs instead of the plain camera input, only when input is not suspended (app mode 0, no
blocking sequence). Keys are the held-key table (`movement.md` "Keys"). In order:

1. State 1 and Up or Down held: `Stop`, `moved` := true.
2. State 2 and Left, Right, PgUp or PgDn held: `Stop`, `turned` := true.
3. `onStone`, `turned`, not `glassesTaken`, state ≠ 4: `Start(4, "Take")`.
4. Shift held and `onStone`: **jump off** (below) and end the hook (no camera input).
5. Space held: `spaceSeen` := true; if state 8, `Stop`. **Dead in practice** (E-0214): the
   bar consumes Space before it reaches the key table, so this never fires; do not
   implement it (or gate it the same way), else `sb10`/`sb11` stop too early.
6. Normal camera input (walk, turn, collision, ground).
7. **Step onto the stone**: not `onStone` and the ground object is named exactly
   `*U04_32`. The ground object is the object whose face the walking ground cast
   (`movement.md`) hit highest; it changes only in that step (while moving with collision
   on) and is cleared by the jump off. A hit on one of the boat's children (`*U04_30`,
   `Line07`, …) does not count; there is no parent walk (E-0231): `onStone` := true; eye := the stone hotspot's position (its object's global
   position when the hotspot was created) + (0, 0, 10); can move := 0; collision off;
   look at `*U04_43`'s object at once (`LookAt(0, …)`); if not `turned`: `Start(2, "Tourner")`.
8. **Near Monet**: `glassesTaken`, not `spaceSeen`, state ≠ 8, and the eye within 2·s = 20
   units (3D distance) of Monet's hotspot position, i.e. his object's global position when
   the hotspot was created at Start step 3, not his current one (E-0231): `LookAt(1000, Monet's object)`, `nearMonet` := true,
   Say(`sb10`, no cut), `Start(8, "")`.

**Jump off** (`onStone` and Shift): `onStone` := false; `MoveTo(2000, (149.87, 60.56,
−9.0), yaw 0.427, pitch π/2)`; can move := 1; collision on; ground object := none; if state
2, `Stop`. It is a scripted move, not `movement.md`'s jump (jump is not enabled in U00);
the next ground snap sets the eye height.

## The glasses (click handler, E-0202)

The unit's queue handler (as U01's) runs, per queued action:

- **`TakeLunettes`** (M01: the click took `*U04_80`, the cursor holds `U04_80C`): `Stop`,
  `Start(7, "")`, `glassesTaken` := true. The player now opens the bar with Space and
  clicks the strip to store the glasses (`ui.md` inventory bar); state 7 nags with `sb09`
  while they stay on the cursor.
- **`DonnerLunettes`** (M02: glasses used on Monet) — the ending:
  1. Cursor back to normal (the held glasses are gone); suspend; `spaceSeen` := true;
     `Stop`.
  2. Monet's node plays `U04/ANIM/U04_03_Lunettes/prend.A3D` once (a new slot named
     `monet`, running, not looping). `MoveTo(1000, P₀, yaw 4.67, pitch 1.47, FOV 90)`:
     the full start pose, not only the position (E-0202).
  3. Wait (frames) until that clip pauses at its end. Show `*U04_81`.
  4. Play `MET.A3D` from the same folder the same way. Say(`sb14`, no cut).
  5. Wait until the clip's frame reaches 50; show `*U04_81` (again); wait until it pauses.
  6. `RunFor(2000)`.
  7. Open the Option menu (frame manager `+0xc0(0)`, the path `SelectUser` takes for a known
     player; app mode 2). Resume input.

## Interactables and the goal (E-0232)

| Hotspot | Type | Cursor | Click | Use item |
|---|---:|---:|---|---|
| `*U04_03` Monet | 6 | 0 | nothing | `U04_80` (the glasses): M02 → `DonnerLunettes`, the ending |
| `*U04_32` the boat | 5 | 0 | nothing (stepping onto it is the input hook's) | nothing |
| `*U04_36` | 4 | 0 | hidden, never shown: unreachable | — |
| `*U04_43` | 4 | 0 | nothing (the look-at target on the boat) | nothing |
| `*U04_80` the glasses | 4 | 4 take | M01 (once): take them (hidden, cursor `U04_80C`, the bar slides up), `TakeLunettes` | nothing |

There is no other action and no other unit handler. The goal is the only exit besides
Escape: give the glasses to Monet, which ends in the Option menu.

**The designed path**, from the conditions (what the lines say: Q-0120): `sb03`; walk
(Up; else `sb04` every 10 s with a cut to P₀) → walk onto the boat (parked, looking at
`*U04_43`) → turn (else `sb06`) → 10 s later `sb07`, then `sb08` every 10 s until the
glasses are clicked → the take raises the bar; `sb09` every 10 s while they stay on the
cursor → click the strip to store them (no Space needed) → `sb05` every 10 s until Shift
→ jump off → walk to within 20 units of Monet → `sb10`, then `sb11` every 10 s (blocking)
until the glasses are given → Space, click the glasses in the bar, click Monet → `prend`, `MET`, `sb14` → Option menu.

Shortcuts the code allows: the glasses can be taken from the bank if they are within the
pick depth of 4·s = 40 (then no boat hints: after storing them the gauge just stops);
holding them, a click on Monet ends the tutorial at once. Space does not skip `sb10`/`sb11`
(E-0214). After the jump, walking back onto the boat parks the eye there again (E-0215).
Leaving the boat
before turning stops the hints until the boat is reached again.

## Escape (E-0105, E-0201)

U00 never changes "Escape allowed" (no store to app `+0x484` in U00's code), so Escape works
whenever the main loop runs: not during a Say, the jump-off move or the ending (blocking
sequences, E-0043). Remarks do not block. On the players screen (app mode 2, `OptionUser`)
Escape quits. In the tutorial (app mode 0, no game started) Escape (or F5) leaves a held
item on the cursor (it stays drawn over the menu; Practice then stores it in the bar, New
game loses it, E-0212), stops group 1 (the `s3_01` ambient) and opens the Option menu; the
tutorial does not resume. From the menu, New game goes to U01 and Practice reloads U00.

## Engine notes

- The gauge counts wall-clock ms and is advanced by the frame draw, so it also runs during
  blocking sequences (they render). Every restart follows the line it belongs to, so the
  10 s are counted from the end of a Say, but from the start of a Remark.
- Distances and positions assume `s` = 10; the stone's position comes from the scene, not
  a constant.
- A player name list and `practice` are process-wide in the original; the engine keeps
  them in its session state.
