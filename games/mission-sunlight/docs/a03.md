# A03: zones 4, 7, 12, 13, 16, 18

The 2D zones whose pictures are named `A03_*`. Generic parts (zone screen, bar, placing,
running a slot, result, sunflower, and the words tick, click, release, background,
movie n, voice, sound, cursor n): `engines/peintre/docs/spec/ui.md`. All count on sunflower
counter 2. "Wait for the voice" = until it ends or a click (0x414dec). Puzzles that end
early after Backspace end with result 0 (the object goes back to the bar). Evidence:
E-0427.

   `A03_012b`. Backspace ends the slot (result 0). A click on hot spot h: seen[h] = 1,

3. After the movie, 60 ticks, then on release: if all three are seen, go to 4 with

4. Background, the slots and looping sprite `A03_012<e + h>` (`e`, `f` or `g`) from frame 0 (one

   f is 16..27 and it is in rect B[f]; a click there ends the loop (sprite freed, sound

## Zone 18, `A03_06`

One object, **28**; `onPlace` 0x405e8c, `onAbort` 0x405f5b; slot function 0x405fa6.

### Object 28: click at the right moment

On placing: sprite banks `a03_06b`, `a03_06c`, `a03_06d`, `a03_06e` (scenes k = 0..3),
k = 0, movie 27 (`A03_06a`, not skippable).

1. After the movie: background `a03_06f`, the slots, voice `a03_06b`; wait for it.
2. Scene k: static sound `a03_06<i + k>` (`a03_06i`..`l`), sprite k played once from frame
   0 (one frame per odd tick) with its sound.
3. Each tick: cursor 11 when the sprite's next frame index is inside window[k] and the
   cursor is in (293, 133, 124, 35). Backspace ends the slot (result 0). A click there:
   k = 2 → stop the sound, background `a03_06`, the slots, go to 4; other k → voice
   `a03_06<c + k>` (`c`, `d`, `f`) and wait for the release while the scene plays on.
   When the sprite ends: its sound stops, k = (k + 1) mod 4, back to 2.
4. On release: voice `a03_06e`, then `a03_06g`, then `a03_06h` (each waited for), 60
   ticks, result 1.

Windows (0x4a5138): k = 0: 23..31, 1: 35..41, 2: 36..44, 3: 19..25.
