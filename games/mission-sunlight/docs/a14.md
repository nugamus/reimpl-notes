# A14: zones 0, 20, 21, 24

The 2D zones whose pictures are named `A14_*`: the first zone of the game (0), two
puzzles (20, 24) and the ending (21). Generic parts (zone screen, bar, magnifier, views,
placing, running a slot, result, sunflower, and the words tick, click, release,
background, movie n, voice, sound, cursor n): `engines/peintre/docs/spec/ui.md`.
Backspace ends a puzzle with result 0 where noted. Evidence: E-0431.

## Zone 0, `A14_031a`: the first zone

One object, **0**; counter 0, sunflower picture `TOURN1`. It teaches the magnifier and
the sunflower. On entry the zone opens the bar at once instead of showing the Retour
buttons (state 0, `ui.md`); the player drags object 0 onto its slot.

Placing it plays movie 32 (`A14_031a`, not skippable, 0x4119fc); then the slot function
0x411a28:

1. After the movie: background `a14_031b`, the slots, the magnifier drawn open (last
   frame of `LoupeOut`), cursor 0.
2. Cursor 11 over view A or view B, else 0. A click on view A: sound `clic_1`, the view A
   animation (`A14_03a`); on view B: sound `clic_1`, the view B panorama (`A14_03b`); each
   waits for the release first, and when it ends: background `a14_031b`, the slots, the
   magnifier open, the view marked seen; then on release back to 2. Once both views are
   seen, or after 250 ticks in step 2, go to 3.
3. Movie 33 (`A14_031b`, not skippable).
4. After it: background `a14_031c`, the slots, sprite bank `A14_031a`, `TOURN1`, sound
   `tourneso`.
5. Cursor 12 over the sunflower (111, 244, 24, 32), else 0. A click there: `A14_031a`
   frame 1 at (31, 198), `TOURN1` follows the cursor (grab offset (132, 295)), sound
   `tourneso`, cursor 13.
6. On release: the sprite's point (132, 295) + cursor − grab point inside (590, 400, 45, 80) → counter 0 = 1, movie 34 (`A14_031c`,
   skippable); elsewhere `A14_031a` frame 0 at (31, 198), sound `cf_clic3`, back to 5.
7. After the movie: background `a14_031d`, the slots; 40 ticks; result 1.

Then `CapsAC` closes the slot, the game autosaves (slot 0) and the zone is left with -1.

## Zone 20, `A14_01`: three wheels

One object, **31**; counter 3; `onPlace` 0x407509, `onAbort` 0x4076b2; slot function
0x40770c.

Three wheels w = 0..2, each in state 0..2; start states 2, 2, 1; the goal is 0, 0, 0
(0x4e0558: never written, zero). Wheel w in state s turning shows sprite bank
`N[w][s]`: w = 0: `a14_01h`, `a14_01i`, `a14_01j`; w = 1: `a14_01b`, `c`, `d`; w = 2:
`a14_01e`, `f`, `g` (0x4a5808). On placing: the start sprites, sound `a14_01e`, sound
`reussit`, movie 54 (`A14_01a`, not skippable).

1. After the movie: background `a14_010a`, the slots, voice `a14_01b`; wait for it (a
   click cuts it), stop it.
2. Cursor 11 over a wheel rect, else 0. Backspace ends the slot (result 0). A click on
   wheel w: `N[w][s_w]` plays once at the rect's (x, y) (one frame per odd tick), sound
   `a14_01e`, cursor 9.
3. When it ends: s_w = (s_w + 1) mod 3 (its sprite is opened if needed). All wheels at 0:
   sound `reussit` → 4; otherwise on release back to 2.
4. After 51 ticks: background `a14_01`, the slots, voice `a14_01c`; wait for it, stop it;
   9 more ticks (the same count runs on to 60); result 1.

Wheel rects (0x4a57d8): (153, 29, 335, 140), (153, 170, 335, 185), (153, 356, 335, 73).

## Zone 21, `A14_032a`: the ending

No object and no bar. `Entry2D` first writes `GGAME` (flag 0); the zone runs 0x412065
(state 0x24):

1. Background `a14_032a`, movie 64 (`A14_032a`, not skippable).
2. After it: background `a14_032b`, cursor 9; wait for the release.
3. Cursor 11 over (121, 325, 41, 45), else 0; a click there: movie 65 (`A14_032b`, not
   skippable).
4. After it: cursor 9, wait for the release, 60 ticks; leave with -1.

The 3D side then plays `cinefin`, `cinefin2` and the credits, and quits
(`engines/peintre/docs/spec/boot.md` "End of the game").

## Zone 24, `A14_02`: uncover, then five pieces

One object, **34**; counter 3; `onPlace` 0x407bc7, `onAbort` 0x407dd1; slot function
0x408118.

On placing: a mask of 185,376 bytes (479 × 387 + 3, the last 3 set to 0xFF); sprite banks
`a14_021a` (loose pieces, frame i) and `a14_021b` (placed pieces); the brush size = the
size of `Curseurs` frame 10; sounds `reussit`, `p_clic2`, `p_clic3`, `p_clic4`, `p_clic1`,
`cf_clic3`; movie 28 (`A14_02`, skippable).

1. After the movie: `a14_020a` is loaded into the back buffer (the hidden picture), then
   background `a14_02` on screen, the slots; wait for the release.
2. **Uncover**: cursor 10 inside x 112..590, y 29..415, else 0. Backspace ends the slot
   (result 0). While the button is down inside the area, sound `p_clic1` loops as long as
   the cursor moves (stopped when it stays still, leaves or the button is released), and
   each tick the brush rectangle (brush size, centred on the cursor, clipped to x ≥ 112,
   y ≥ 29, x < 591, y < 416) is copied from the hidden picture to the screen and marked in
   the mask (row stride 479, origin (112, 29)). When fewer than 9,251 of the mask's 46,344
   u32 words still hold an unmarked byte: sound `p_clic2`, wait for the release, go to 3.
3. Movie 57 (`A14_02a`, not skippable).
4. After it: background `a14_020a`, the slots, the five pieces (`a14_021a` frame i at the
   (x, y) of pick rect i), voice `a14_02c`; wait for it, stop it; hint count 125.
5. Cursor 12 over an unplaced piece's pick rect, else 0. Backspace ends the slot. Each
   tick +1; above 500: voice `a14_02d`, count 0. A click on piece i: its background is
   restored, it follows the cursor, sound `p_clic3`, cursor 13.
6. On release, with q = the piece's reference point + (32, 32): if q is in drop rect i:
   sound `p_clic4`, `a14_021b` frame i at its placed position, placed, count 125; all
   five placed → 7. Otherwise the piece is drawn back, sound `cf_clic3`, count 0. Back to 5.
7. After 25 ticks: sound `reussit`; 60 ticks; result 1.

The hit test takes the first drop rect containing q; only the piece's own rect counts.
