# A13: zones 5, 6, 8, 9, 10, 11, 14, 15, 17

The 2D zones whose pictures are named `A13_*`. Generic parts (zone screen, bar, placing,
running a slot, result, sunflower, and the words tick, click, release, background,
movie n, voice, sound, cursor n): `engines/peintre/docs/spec/ui.md`. All count on sunflower
counter 2. "Wait for the voice" = until it ends or a click (0x414dec). Backspace ends a
puzzle with result 0 where noted (the object goes back to the bar). Evidence: E-0430.

## Zone 8, `A13_03`

Objects **13** (slot 0) and **14** (slot 1); `onPlace` 0x403346, `onAbort` 0x4034f2.

### Object 13: six rounds of two choices (0x4035fb)

On placing: sounds `reussit`, `cc_clic2`, `pt_clic3`, `cc_clic4`, `cc_clic1`; voice
`A13_031`; round r = 0.

1. Wait for the voice; background `a13_031`, the slots, voice `a13_031b`; wait for it.
2. Round r: sprite banks `a13_031<a + 2r>` (first) and `a13_031<b + 2r>` (second), i.e.
   `A`/`B`, `C`/`D` .. `K`/`L`. Play the first once at (0, 0), one frame per odd tick,
   cursor 9, sound `cc_clic4`; at its end keep its last frame.
3. Choose: cursor 11 over one of the two rects, else 0; after 250 ticks voice `a13_031c`.
   Backspace ends the slot (result 0). A click on rect c: the first sprite's background
   is restored, the second plays once (sound `cc_clic1`); when it reaches frame index 15,
   sound `cc_clic2` if c = answer[r], else `pt_clic3`.
4. When it ends: r + 1; r < 6 → 2; else on release, 60 ticks, result 1. The answers only
   choose the sound: the object is always accepted.

Rects (0x4a4b50): c = 0 (122, 39, 217, 170), c = 1 (122, 224, 217, 170). Answers
(0x4a4b70): 1, 1, 0, 0, 0, 1.

### Object 14: join the six pairs (0x403a1a)

On placing: background `a13_032c`, the slots; the rect (110, 29, 482, 386) is kept as the
clean picture; sprite bank `a13_032` (28 frames); every element drawn; sounds `cc1_clic`,
`reussit`; voice `a13_032`; nothing selected.

Six elements e, each with two halves h. The player clicks one half (it is selected), then
the other half of the same element: the element is joined. Clicking the selected half
again unselects it; clicking another element selects that one instead.

1. Wait for the voice.
2. Backspace ends the slot (result 0). A click: find (e, h) (below); if found:
   - e is the selected element, h the other half: animate (3);
   - e is the selected element, same half: unselect;
   - otherwise select (e, h), redrawing the previously selected element plain.
   Then wait for the release. The hint count rises twice per tick; above 625: voice
   `A13_032b`, count 0.
3. 25 ticks: sound `cc1_clic` once; each tick the element is redrawn with the selected
   half following the tick's parity. Then: stop the sound, the element is joined, the
   clean picture is put back and every element not yet joined redrawn. All six joined:
   sound `reussit`, 50 ticks, voice `A13_032c`, wait for it, result 1. Otherwise back to 2.

**Hit test** (0x403215): for e = 0..5, h = 0..1, the first rect[e][h] containing the
cursor whose element is not joined; if that is (4, 0), element 5 is not joined and the
cursor is also in (120, 206, 77, 135), the result is (5, 0) instead.

**Drawing element e** (0x402e76; nothing if joined; s = selected half, or the tick parity
during 3). Frames are drawn at pos1[e] and pos2[e]:

- e = 0..3: selected → frames `(1 - s) × 14 + 2e` and `s × 14 + 2e + 1`, else `2e`, `2e + 1`.
- e = 4: frames `f1`, `f2` at pos1/pos2 and `f3` at (118, 184) when f3 ≥ 0. Selected 4:
  `f1 = (1 - s) × 14 + 8`, `f2 = s × 14 + 9`, `f3 = (1 - s) + 10` if 5 is not joined, else
  none. Selected 5: `(1 - s) × 14 + 8`, `s × 14 + 9`, `(1 - s) × 14 + 10`. Neither: 8, 9 and
  10 (none if 5 is joined).
- e = 5: frames `f1`, `f2` at pos1/pos2. Selected 5: `f1 = (1 - s) × 14 + 12` if 4 is joined,
  else `(1 - s) × 14 + 10`; `f2 = s × 14 + 13`. Selected 4: `f1 = (1 - s) + 10`,
  `f2 = s × 14 + 13`. Neither: `f1` = 10 if 4 is not joined, else 12; `f2` = 13.

(The `(1 - s) + 10` terms without `× 14` are as in the code.)

### Object 24: sixteen pieces

On placing: sprite bank `A13_061` (frame p = piece p), sounds `reussit`, `pa_clic1`,
`pa_clic2`, `pa_clic3`, voice `a13_061`. The stack holds all 16 pieces; the board none.

1. Wait for the voice, stop it; movie 55 (`A13_061a`, not skippable), then movie 56
   (`A13_061b`, not skippable).
2. Background `a13_061a`, the slots; the rect (156, 29, 328, 400) is kept as the empty
   board. The stack is drawn: pieces `order[0]`..`order[15]` in that order, each centred
   on its stack position (so `order[15]` = piece 0 is on top).
3. Cursor 12 over the top stack piece or a board piece, else 0. Backspace ends the slot
   (result 0). A click:
   - on the top stack piece (its frame rectangle centred on its stack position): it
     follows the cursor (sound `pa_clic1`) → 4;
   - else on a board piece (the last placed one first): the board is redrawn without it
     and it follows the cursor (sound `pa_clic1`) → 5.
4. Release of a stack piece at point q (0x40497d):
   - q within 4 px of the piece's target (`tx - 4 ≤ x < tx + 4`, same for y): it snaps to
     the target, sound `pa_clic2`, it counts as right;
   - else if the piece, centred on q, lies inside x 156..483, y 29..428: it stays at q
     (wrong);
   - else it goes back on the stack, sound `pa_clic3`.
   A piece that left the stack reveals the next one.
5. Release of a board piece: as in 4, but outside the board it returns to where it was;
   placed at q it is wrong; each case plays `pa_clic3` except the snap (`pa_clic2`).
6. After a snap with the stack empty and all 16 right: sound `reussit`, 60 ticks, result 1.
