# A01: zones 1 and 2

The 2D zones whose pictures are named `A01_*`. Everything generic (zone screen, bar,
placing an object, running a slot, the result, the sunflower, words like tick, click,
background, movie n, voice, sound, cursor n) is in `engines/peintre/docs/spec/ui.md`;
movie numbers are rows of the 2D movie table (E-0204). Both zones count on sunflower
counter 1. Evidence: E-0426.

## Zone 1, `A01_02`

One object, **1**, slot 0. Placing it plays movie 29 (`A01_02`, skippable); the slot ends
with the movie, result 1 (0x40d0f0, 0x414dcc).

## Zone 2, `A01_03`

Objects **3** (slot 0) and **2** (slot 1). `onPlace` 0x40d112, `onAbort` 0x40d1ef.

### Object 2

Voice `A01_031`; the slot waits for it (a click cuts it), result 1.

### Object 3: the five pieces (slot function 0x40d293)

On placing: background `a01_032a`, movie 0 (`A01_032a`, not skippable), sprite bank
`a01_032a` (frame i = piece i), sounds `pt_clic1`, `pt_clic2`, `pt_clic3`, `reussit`.
Piece counter i = 0.

1. When movie 0 ends: background `a01_032a`, the slots, voice `a01_032`.
2. When the voice ends (or a click): stop it; movie 1 (`A01_032b`, not skippable).
3. When the movie ends: background `a01_032<a+i>` (`a01_032a` for i = 0), the slots, and
   piece i drawn at its position.
4. Wait for the player: cursor 12 over piece i's pick rect, else 0. After 250 idle ticks
   (button up) voice `a01_032b` and the count restarts. Backspace ends the slot here with
   result 0 (the object goes back to the bar). A click inside the pick rect picks the
   piece up (sound `pt_clic1`, cursor 13); it follows the cursor.
5. On release: if the piece's reference point is inside its drop rect: cursor 9,
   background `a01_032<b+i>`, the slots; if i = 4, sound `reussit` and go to 6; otherwise
   i + 1, movie i + 1 (`A01_032c`..`f` for the new i = 1..4, not skippable), sound
   `pt_clic2`, back to 3. Outside: the piece is drawn back at its position, sound
   `pt_clic3`, back to 4.
6. After 60 ticks: movie 6 (`A01_032l`, not skippable); when it ends voice `a01_032c`;
   when that ends (or a click) the slot ends with result 1.

Pieces (table 0x4a62c0; position, pick rect x, y, w, h, drop rect x, y, w, h):

| i | Position | Pick rect | Drop rect |
|---:|---|---|---|
| 0 | 573, 403 | 532, 361, 84, 85 | 205, 122, 71, 89 |
| 1 | 553, 384 | 489, 295, 130, 177 | 124, 112, 75, 180 |
| 2 | 572, 405 | 549, 356, 47, 97 | 309, 114, 40, 78 |
| 3 | 573, 404 | 532, 337, 83, 132 | 284, 198, 54, 97 |
| 4 | 566, 384 | 527, 299, 103, 173 | 393, 110, 90, 184 |

The reference point is the piece's position moved with the cursor (the offset between the
position and the grab point is kept).
