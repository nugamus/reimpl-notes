# U33: the fairground at night (projectionist, caravan, clown, policeman)

Everything unit 33's code (vtable `0x00439560`, constructor `0x00407090`, E-0075) does on
top of the generic scene: the renames and hides of its start hook, the entry from U03, the
frame hook (the projectionist's nag, the clown's search, two escape gauges), the
dispatcher's curtain trap, the eighteen handlers named by op 10, and the exit to U04 on the bike.
No assert names its source file (the EXEs name only `U00.cpp`, `U03.cpp`, `U04.cpp`,
`U99.cpp`); functions are named `U33::*` in Ghidra (E-0420).

Conventions are those of `u01.md` and `u02.md`: `RunFor`, `MoveTo` (100.0 = keep),
**suspend** / **resume**, `Mnn` = the INFOACT record with id nn
(`infoact.py --file Data/U33/INFOACT.BIN`), "Mnn exhausted", "run Mnn" (its steps, then
its count, `interaction.md`), `Say`, "effect X at P" (effects emitter, group 3). From
`u03.md`: **`WalkPath(ms, from, to, yaw₀→yaw₁, pitch₀→pitch₁, callback)`** (straight line,
yaw the short way, no ground snap unless the callback does it; U33 passes a callback once)
and the **ground point `G(x, y, z)`** = (x, y, ground below + h). "Walk to P facing y" =
`WalkPath` from the eye to P, yaw from the current yaw to y, pitch from the current pitch
to π/2. "Tick and render" = one animation tick and one rendered frame, no input.

`s` = 45 (`SCENE.BIN`: ambient 225/220/220, FOV 90, sphere radius 20, Z offset 40;
eye height h = 1.5 · s = 67.5; E-0431). U33 has no input hook of its own (vtable `+0x40`
is `Scene_HandleInput`), no load hook (`+0x10` is the generic load) and no save chunk
(`+8`/`+0xc` are the generic ones; `save.md`).

## Place in the game (E-0420)

- **From U03:** U03's `DoCinematiqueFlic` ends by storing `U33.X3D` as the next scene and
  setting app mode 1 (`u03.md`, step 16). It does not change the game's unit number, so
  U33 plays as **unit 3**: saves and the players list record 3 (`save.md`). The debug key
  8 (`Scene_HandleInput`) reaches the same scene through "go to unit 8", which also sets
  3. Nothing else loads `U33.X3D`.
- **To U04:** `TransitionVelo` ends with "go to unit 4" (`U04.x3d`).
- `U33D.X3D` is a different file: the documentation scene loaded for gallery entry
  `U12_04` (`FUN_004131e0`), not this unit.

The data is U03's cast and set at night: `Data/U33/Anim/U03_01`, `U03_02`, `U03_09`, the
caravan (`roulotte`), the projector and screen (`Prefilm`), the trunk, the bikes.

| Name | Meaning | Initial |

M92 exhausted and M02's count 0 (inside the caravan) turns run and jump off again.

## Every frame (`U33::UpdateFrameLogic`, E-0422)

Before rendering, in order:

1. **Caught in the caravan:** if M92 is exhausted (the player went in with the key) and
   M58 is not (not hidden behind the curtain) and the gauge has expired (the check resets
   it): run `DoGameOverClown1` and **skip this frame's render**.
2. **The projectionist's nag:** if M05 is exhausted and M06 is not: if `timer` = 0,
   `timer` := now; if now > `timer` + 25000 and the voice group is silent: run M06 (he
   says `U03_01_11`; M06 then counts as exhausted), `timer` := 0.
3. If M08 is exhausted and M06 is not: M06 := exhausted (no nag once the reel is taken).
4. **The clown searches:** if M62 is exhausted, M64 and M63 are not, and the voice group
   is silent: if `timer` = 0, `timer` := now; if now > `timer` + 7000, run M63 (the clown
   says `U03_01_24`, effect `s2_19`). `timer` is not reset here, and step 3 leaves it
   unreset: if the reel was taken before the nag fired, `timer` still holds that old
   value and M63 runs as soon as M62's voice ends (E-0422).
5. If M62 and M63 are exhausted, M64 is not, and the voice group is silent: M64 :=
   exhausted (the search is over).
6. **The policeman's gauge:** if M85 is exhausted and the gauge has expired (reset):
   game over at once (stop every sound, `OptionLoad`; the "caught" of `u01.md` step 8,
   without a fade or animation).

Then render (the gauge is drawn as in `u01.md`).

### The films (E-0425)

**Walk to the screen** (`U33::WalkToScreen`): suspend. Walk to G(699, 61, eye.z) facing 0
over 6000 ms. Then `WalkPath` 6000 ms from the eye to (825.89, 60.1939, 62) (no ground
point), yaw → 0, pitch → π/2, with the **countdown callback**. Show `Box186`. Cut the eye
to G(699, 61, first eye.z). Resume.

**Countdown callback** (`U33::CountdownCallback`, step i of N): k = ⌊N / 15⌋; when
i mod k = 0, j = i / k + 1; if 0 < j < 16: hide `Box186`, hide `*Ecran01`'s parent (all
frames), show frame `*Ecran0t` (or `*Ecran10`) with t = T[j], T = 9, 8, 10, 7, 9, 6, 10,
5, 9, 4, 10, 3, 9, 2, 10, 1 (T[0..15]). j starts at 2, so the frames shown are 10, 7, 9,
6, 10, 5, 9, 4, 10, 3, 9, 2, 10, 1, one every k steps (a film leader counting down).
N = ⌊6000 · fps / 1000⌋; at 30 fps, k = 12 (0.4 s).

**After a film** (`U33::AfterFilm`): stop the effects emitter; cut the eye to
G(686, 90, 68), yaw 2.16, pitch π/2.
